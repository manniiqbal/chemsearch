# ChemSearch frontend

The Next.js client for the ChemSearch reaction workspace. It provides typed simulation and prediction workflows, selected-candidate state, responsive scientific dashboard styling, and real RDKit SVG molecule depictions supplied by the backend.

```bash
cp .env.example .env.local
npm ci
npm run dev
```

Use `npm run lint` and `npm run build` before shipping. Full setup, architecture, API examples, supported chemistry, Docker instructions, and limitations are documented in the [project README](../README.md).
